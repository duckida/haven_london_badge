# haven london PCB badge
This is a PCB attendee badge for [Hack Club Haven London](haven.london)!

I spent 2.5hrs designing this in Excalidraw and KiCAD!

It has silkscreen designs, a space to write your name, bare copper Daven (ooh shiny), and optional places to add electronics:
- CR2032 battery holder
- 2x 5mm LEDs
- 47Ω resistor
- Push button to turn them on

The PCB production was sponsored by PCBWay, thank you sm!
